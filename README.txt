دعوة زفاف فيكتورية — ملفات المشروع

الملفات:
- index.html: محتوى الدعوة
- style.css: التصميم والحركات والاستجابة للموبايل
- script.js: الأسماء والتاريخ والوقت والمكان ورابط الخريطة
- assets/waltz.mp3: ضعي هنا ملف موسيقى فالس مرخّصًا بصيغة MP3

تخصيص الدعوة:
افتحي script.js وعدّلي قيم كائن wedding:
groom, bride, dateShort, dateFull, time, venue, mapUrl

تشغيل محلي:
افتحي index.html في المتصفح. قد تحتاج الموسيقى إلى رفع الموقع أو تشغيله عبر خادم محلي.

النشر على GitHub Pages:
1. ارفعي index.html وstyle.css وscript.js ومجلد assets إلى جذر المستودع.
2. من Settings > Pages اختاري النشر من فرع main ومجلد /(root).
3. أضيفي ملف assets/waltz.mp3 بنفسك؛ لم يتم تضمين موسيقى محمية بحقوق نشر.
4. افتحي رابط GitHub Pages بعد اكتمال النشر.

ملاحظة:
الخطوط تُحمّل من Google Fonts عند توفر الإنترنت. التصميم الأساسي يبقى صالحًا إذا تعذّر تحميلها.
